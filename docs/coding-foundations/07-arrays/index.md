# Module 07: Arrays

## Scope

Arrays are the bedrock for most DS&A questions and need to be treated as a memory and indexing model, not just a container.

## Interview Deep Dive

Continue with [Interview Deep Dive](02-interview-deep-dive.md) for decision rules, correctness proofs, worked traces, production trade-offs, model interview questions and answers, and a progressive practice ladder.

## Runnable Reference

The deep-dive chapter links the matching Java implementation under `examples/java/src/main/java/` so theory and runnable code remain easy to navigate independently.

## Complete Arrays Learning Path

Follow the module in this order:

1. [Array Mental Model](01-array-mental-model.md): establish the baseline representation and vocabulary.
2. [Interview Deep Dive](02-interview-deep-dive.md): practice invariants, traces, trade-offs, and model answers.
3. [Array Foundations](03-array-foundations.md): move from storage and indexing through mutation, resizing, matrices, Java APIs, and production concerns.
4. [Array DSA Pattern Catalog](04-array-dsa-patterns.md): learn recognition signals, invariants, complexity, and failure conditions for the major array patterns.
5. [Advanced Arrays Interview Playbook](05-advanced-array-interview-playbook.md): combine patterns, study full derivations, review 20 concept Q&As, and follow a staged preparation roadmap.
