# Number Systems Exercise Guide

Every chapter ends with a delayed-practice structure:

- Quick Check: retrieve concepts without code;
- Coding Practice: implement the chapter invariant;
- Debugging Task: identify a concrete violated contract;
- Interview Extension: adapt the solution when an assumption changes.

Use this order for each chapter:

1. Write the input contract and type/range assumptions.
2. Attempt the Quick Check without reopening the chapter.
3. Implement at least one Foundation and one Interview Core problem.
4. Compile and test zero, signs, boundaries, invalid input, and overflow.
5. Diagnose the buggy snippet with a smallest failing input.
6. Explain one follow-up aloud before consulting the delayed guidance.

Part B contains the full assessment across Chapters 15A and 16: 40 conceptual questions, at least 30 Java-specific questions, 25 code-output questions, 25 debugging questions, 30 Foundation problems, 30 Interview Core problems, 20 SDE-2 follow-ups, and ten interviewer discussion chains. Do not open delayed checkpoints until the corresponding question set has been attempted.

Record mistakes in six buckets: contract, representation, numeric range, invariant, complexity, and Java semantics. Repeat missed items after one, three, seven, and fourteen days.
