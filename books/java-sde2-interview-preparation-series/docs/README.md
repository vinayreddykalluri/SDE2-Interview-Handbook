# Book Documentation

This directory contains current editorial guidance, not chapters or generated evidence.

- [`editorial-standard.md`](editorial-standard.md) defines the learning, accuracy, exercise, code, and PDF expectations for an expanded volume.
- [`roadmap.md`](roadmap.md) gives readers and contributors the prerequisite order, completion gates, and cross-book route.

Canonical prose belongs under `../content/`; publishing metadata belongs under `../publishing/`; audits and build evidence belong under `../reports/`.
