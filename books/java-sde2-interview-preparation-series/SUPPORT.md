# Support

## Reading and study questions

Use GitHub Discussions when enabled. Include the volume, chapter, page, concept, and what you expected to happen.

## Corrections and build defects

Open a GitHub issue using the closest template:

- content correction;
- new topic or educational improvement; or
- build/PDF defect.

## Private concerns

Use [SECURITY.md](SECURITY.md) for credentials, private data, unsafe build behavior, or sensitive conduct evidence.

This is a community educational project, so response times are not guaranteed. Clear reproductions and small focused proposals are easier to review.
